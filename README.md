# Historical Data Analysis

A beginner-friendly Python project for analyzing historical industrial output data.

## Features

- Read CSV data using pandas
- Calculate growth rates
- Calculate annualized growth rates for non-continuous years
- Identify the highest and lowest growth records
- Generate trend charts
- Export analysis results to Excel
- Generate a text summary automatically

## Technologies

- Python
- pandas
- matplotlib
- openpyxl

## Project Files

- `analysis.py` — main analysis script
- `output.csv` — source data
- `analysis_result.xlsx` — exported analysis results
- `output_trend.png` — industrial output trend chart
- `annualized_growth.png` — annualized growth chart
- `analysis_summary.txt` — automatically generated summary

## How to Run

```bash
python analysis.py
